A tiny paper-trading bot for hourly Solana prices. It buys the dip and
sells the bounce: every 4 bars it buys up to 3 symbols trading more than
1.5% below their 12-bar average, then sells each position when the price
climbs back over that average, pays 3%, or 24 bars pass. It never holds
through a slide, which is how it beats buy-and-hold on a falling window.

## Run it

```sh
python3 main.py
```

The bot speaks the bars-replay/v1 protocol on stdin/stdout (hello, batch,
reply per bar). Deterministic: the same bars always produce the same
orders. Python 3 standard library only, no network, no randomness.
